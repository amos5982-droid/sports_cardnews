# 안드로이드 앱(APK)

카드뉴스 제작기를 휴대폰에 앱으로 설치하는 파일이에요. 앱을 열면 웹 주소의 제작기를 앱 창으로 보여 줘요.
웹 쪽을 고쳐서 올리면 앱을 다시 설치하지 않아도 다음에 열 때 새 버전이 보여요(인터넷이 되면 늘 새로 받아요).

## 설치하는 법 (안드로이드 10 이상)
1. 휴대폰 크롬에서 아래 주소를 열어 파일을 내려받아요.
   - 스포츠: `https://amos5982-droid.github.io/sports_cardnews/android/sports-cardnews.apk`
2. 내려받은 파일을 눌러요. "출처를 알 수 없는 앱" 설치를 허용하라고 하면, 크롬(또는 파일 앱)에 한 번 허용해 줘요.
3. 구글 Play 프로텍트가 "검사되지 않은 앱"이라고 알려 줄 수 있어요. 직접 만든 앱이라서 나오는 안내예요. "설치"를 누르면 돼요.
4. 홈 화면의 "스포츠 카드뉴스" 아이콘으로 열어요.

## 앱에서 달라지는 점
- 저장하면 사진 앱의 **Pictures/카드뉴스** 앨범에 들어가요. JSON 같은 다른 파일은 Download 폴더에 들어가요.
- 제미나이, 구글 계정 선택은 휴대폰의 브라우저나 제미나이 앱으로 열려요.
- 디자인 참고 이미지는 휴대폰 사진에서 골라요.
- 브라우저가 아니라서 화면 위의 "앱 설치" 버튼은 보이지 않아요.

## 다시 만들 때 (보통은 필요 없어요)
웹 주소를 바꾸거나 아이콘, 앱 이름을 바꿀 때만 다시 만들어요. 자바(JDK 11 이상)와 파이썬 3이 있으면 돼요.
```
cd android
./build.sh sports     # android/sports-cardnews.apk가 만들어져요
```
- 안드로이드 스튜디오와 SDK는 필요 없어요. 필요한 도구는 처음 한 번 Maven Central에서 받아 `android/.tools`에 둬요(저장소에는 올라가지 않아요).
- 서명 키는 `~/.cardnews-release.p12`에 만들어져요. **저장소에 올리지 마세요.** 이미 설치한 앱 위에 업데이트하려면 같은 키로 서명해야 해서, 한 사람이 만들어 배포하고 키를 따로 보관하세요. 키가 달라지면 기존 앱을 지우고 다시 설치해야 해요.
- 앱 코드는 `app/MainActivity.java` 하나예요.
